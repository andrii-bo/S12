Аналіз вимірювань антен

Імпортуйте вимірювання NanoVNA/LiteVNA, щоб порівняти S11, S21, КСХ та умовну оцінку підсилення. Без згладжування.

Файли обробляються у вашому браузері та не надсилаються на сервер.

2. Умови вимірювання

Відстань 0,8 м і розміри 0,34 м взято з навчального проєкту. Замініть їх на фактичні значення. Використовуються всі точки файлу.

Оцінка підсилення передбачає вільний простір, дальню зону, вирівнювання та узгоджену поляризацію. Кабельні втрати й неузгодження не компенсуються автоматично. S21 саме по собі не визначає підсилення окремої антени.

Інструкція користувача

  1. Експортуйте вимірювання з NanoVNA App або іншої програми у CSV відповідного формату чи Touchstone 1.x (.s2p). Порядок даних: частота, S11 Re/Im, S21 Re/Im, S12 Re/Im, S22 Re/Im для RI.
  2. Виберіть файл A. За потреби виберіть B для порівняння іншого вимірювання. Калькулятор не визначає, чи це H/V або конкретна антена: назви файлів — лише підписи.
  3. Введіть реальну відстань між антенами, їх максимальні розміри та частоту маркера. Обидва файли мають відповідати введеним умовам; для різних відстаней аналізуйте їх окремо.
  4. Для пари антен з однаковим підсиленням використовуйте перший метод. Для різних антен оберіть еталон і задайте його відоме підсилення. Значення еталона вважається сталим на всій розгортці; якщо воно змінюється з частотою, оцінка коректна лише там, де задане значення відповідає еталону.
  5. Поправка додається до кінцевої оцінки підсилення. Залиште 0 dB, якщо обґрунтованої поправки немає. У режимі однакових антен +0,25 dB змінює оцінку кожної антени на +0,25 dB; це не автоматична компенсація втрат у кабелях.
  6. Натисніть «Розрахувати». Перегляньте значення біля маркера й попередження. Графіки побудовано з усіх точок, без supsmooth та без зсуву +0,25 dB за замовчуванням.
  7. Якщо відстань недостатня, оцінка за Фрісом може бути некоректною. Збільште відстань і повторіть вимірювання. Критерій 2D²/λ — орієнтир; для малих антен потрібні також R ≫ λ та R ≫ D. Відбиття не усуваються самим збільшенням R.
  8. Експортуйте розраховані значення кнопкою під графіками. Експорт містить параметри розрахунку. Калькулятор не зберігає файли після закриття сторінки.
Формули та відмінності від Mathcad

|S| = √(Re² + Im²); S(dB) = 20 log₁₀|S|; КСХ = (1 + |S11|)/(1 − |S11|); λ = c/f.

Втрати вільного простору L = 20 log₁₀(4πR/λ). Для однакових антен G = (S21(dB) + L)/2 + поправка. Для еталона G₂ = S21(dB) + L − G₁ + поправка.

За замовчуванням c = 299 792 458 м/с. Режим Mathcad відтворює наближену арифметику, але використовує всі 401 точки замість 400 та не виконує згладжування. При |S11| ≥ 1 КСХ не обчислюється; нульовий S21 не дає скінченного значення dB або підсилення.

Нульові S12/S22 в експорті не підтверджують, що прилад їх вимірював. Ці канали калькулятор не використовує.
